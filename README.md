# JARVIS V1 Mobile

Mobile Web-App für iPhone/Safari. Chat, Spracherkennung, Sprachausgabe und lokales Gedächtnis funktionieren ohne API-Key. Optional kann Ollama auf einem PC im selben WLAN als KI-Backend verwendet werden.

Öffne `index.html` über einen Webserver (z.B. GitHub Pages) in Safari und füge die Seite zum Home-Bildschirm hinzu.
